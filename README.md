### 🛡️ What I'm building

**[agentscan](https://github.com/Mohammad1sh/agentscan)** — like `npm audit`, but for AI agent extensions.

A zero-dependency CLI that scans Claude skills, MCP servers, Cursor rules and the scripts they ship for prompt injection, data exfiltration, dangerous commands and leaked secrets — then prints a security scorecard so you know what you're installing into your agent.

```bash
npx @meedo01/agentscan .
```
